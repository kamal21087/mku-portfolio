# MKU Dev Portfolio
#### Author:Kamal Uddin
##### Description
This is the personal portfolio of **Kamal Uddin**, showcasing various web development projects and skills, along with contact information and a downloadable resume. The portfolio is built using **React** and **TypeScript**, with a focus on responsive design and clean, modern UI.

The portfolio includes the following sections:

- **About Me**: A brief bio and profile picture.

- **Portfolio**: A showcase of multiple projects with links to live applications and GitHub repositories.

- **Contact**: A form to send messages directly.

- **Resume**: A downloadable resume and a list of technical skills.

#### Features
- **Responsive Design**: Fully responsive and mobile-friendly design.

- **Single Page Application (SPA)**: Uses React Router for smooth navigation between sections without page reloads.

- **Reusable Components**: Built with reusable React components for scalability.

- **Contact Form**: Fully functional contact form with field validation.

- **Portfolio Gallery**: Displays multiple projects with links to live demos and GitHub repositories.

- **Resume Section**: Downloadable resume and a list of proficiencies.

#### Technologies
- **React** (with **TypeScript**)
- **Vite** (for fast builds and optimized development)
- **CSS** (for custom styles)
- **React** Router (for navigation)
- **Netlify** (for deployment)

#### Setup Instructions
To run this project locally:

1. Clone the repository:
```
git clone https://github.com/kamal21087/mku-portfolio.git
```
2. Navigate into the project directory:
```
cd mku-portfolio
```

3. Install the dependencies:
```
npm install
```

4. Run the development server:
```
npm run dev
```

5. Open your browser and go to http://localhost:3000 to view the portfolio locally.

#### Usage
- **Navigation**: Use the navigation bar to browse through the **About Me**, **Portfolio**, **Contact**, and **Resume** sections.
- **Portfolio**: Click on any project card to view the live demo or the GitHub repository.

- **Contact Form**: Submit the form to send a message directly to the developer.
